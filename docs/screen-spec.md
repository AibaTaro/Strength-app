# 画面仕様書

スマホ向けWeb・個人利用。業務ルールは [計画書](../strength-app-plan.md)、実装ルールは [AGENT.md](../AGENT.md)。
画像は `npm run docs:shots` で再生成できる(実装と同期)。

## 1. 全体像

```mermaid
flowchart LR
  S1[S1 今日] -- 開始 --> S2[S2 運動中]
  S2 -- 終了 --> S3[S3 振り返り]
  S1 -. 目的未設定 .-> S4[S4 設定]
  S4 -. 器具・目標 .-> S1
```

下部タブで4画面を切替(戻る操作なし)。運動中は「運動中」タブに緑の●、S1に再開バナー。

```mermaid
stateDiagram-v2
  [*] --> なし
  なし --> 実施中: 開始(候補 or 手動)
  実施中 --> 一時停止: 一時停止
  一時停止 --> 実施中: 再開
  実施中 --> 完了: 終了(確認あり)
  完了 --> [*]
```

## 2. S1 今日 — 候補を作って始める

![S1](screenshots/s1-today.png)

| # | 要素 | 動作 |
|---|---|---|
| 1 | 部位 | 複数選択。未選択=おまかせ |
| 2 | 使える時間 | 15〜90分。初期値=設定の「1回の時間」(なければ30) |
| 3 | 疲労 | 少ない/普通/強い。セッションに保存 |
| 4 | 候補を作る | 候補を生成。0件・例外は理由を赤枠で表示 |
| 5 | 目標値 | 重量(1個あたり)×個数、回数×セット |
| 6 | バッジ | 初回調整 / 教材 確認済み・未確認 |
| 7 | 提案理由 | ロジックが返す文章 |
| 8 | 種目を変える | シートで交換(提案値は再計算)。「外す」で削除 |
| 9 | 開始 | 提案を保存→S2へ |

## 3. S2 運動中 — セットを記録する

![S2](screenshots/s2-workout.png)

| # | 要素 | 動作 |
|---|---|---|
| 1 | セッションバー | 経過時間(時刻差から再計算)、一時停止/再開、終了(確認シート) |
| 2 | 進捗リング | 完了/目標セット。達成で次の種目が自動で開く |
| 3 | 記録済みセット | 編集 / 削除(6秒間「元に戻す」) |
| 4 | 重量 | 16段階の隣へ移動。最小3・最大36kgで停止 |
| 5 | 使用個数 | 2個(両手同時)/ 1個(両手で持つ)。片側種目は左右を選択(確定ごとに自動で反対側) |
| 6 | 回数 | ±1、直接入力可 |
| 7 | 余力 | あと何回できそうだったか(既定=不明) |
| 8 | 痛み・準備 | 下表 |
| 9 | 完了 | 保存+休憩開始。350ms以内の連打は1件のみ |
| 10 | 休憩 | 残り時間、+15秒、スキップ |

**余力・痛み・準備セットの役割**

| 入力 | 目的 | 影響 |
|---|---|---|
| 余力 | 重量が適切かを回数以外で判断 | 直近2回とも上限回数かつ余力2回以上のときだけ増量。余力0〜1回は1段階軽く。不明は増量しない |
| 痛み | 我慢して負荷を上げない安全装置(診断はしない) | 次回の自動候補から除外+理由表示。記録に赤バッジ |
| 準備セット | ウォームアップを本番と分ける | 記録は残る。集計・増量判定・進捗・休憩の対象外 |

## 4. S3 振り返り — 集計と修正

![S3](screenshots/s3-history.png)

| # | 要素 | 内容 |
|---|---|---|
| 1 | 期間 | 前日 / 直近7日 / 直近1か月 |
| 2 | 範囲 | 期間の日付(日本時間)を常に表示 |
| 3 | 集計 | 実施日数・セット数・運動時間+前期間比(比較元0は「比較元なし」) |
| 4 | 種目別 | セット・回数・負荷量=重量×個数×回数(自重は対象外) |
| 5 | 部位別 | 主対象部位のみ加算 |
| 6 | 体重 | 直近5件と前回差。なければ「記録なし」 |
| 7 | 一覧 | 日付別、削除は「元に戻す」付き |

記録ゼロのときは空状態を表示(0や補完値で隠さない)。

## 5. S4 設定 — 入力は自動保存

![S4](screenshots/s4-settings.png)

| # | セクション | 内容 |
|---|---|---|
| 1 | プロフィール | 年齢・身長・主目的・経験・頻度・時間 |
| 2 | 体重と目標 | 体重記録、目標体重(空欄=維持) |
| 3 | ダンベル | 個数、16段階(編集可・初期値に戻せる) |
| 4 | ベンチ | 角度仕様の確認済みトグル(初期=未確認) |
| 5 | プッシュバー | 保有トグル |
| 6 | 避けたい種目 | 選んだ種目は自動候補から除外 |
| 7 | 書き出し・復元 | JSON書き出し。復元は確認シート後に全置換。壊れたファイルはエラー |

## 6. 共通

| 項目 | 仕様 |
|---|---|
| 表記 | ダンベルは常に「1個あたり」。「12kg × 2個」 |
| 時刻 | 日本時間 |
| テーマ | OS設定に追従(ライト/ダーク) |
| 操作 | 主要ボタン高さ44px以上、Escでシートを閉じる |
| 保存 | 端末のlocalStorage。他端末とは共有されない |
